# Plan: Fix Redmi 10A APK Installation - Switch to Godot 4.4-stable for Native Multi-Arch Support

## Problem Summary
- **Device**: Xiaomi Redmi 10A (Android 11, 32-bit userland, PowerVR GE8320)
- **Failure**: "App not installed" — APK contains only `arm64-v8a` native libs
- **Root Cause**: Godot 4.7.2 official export templates are **arm64-only**; 32-bit devices need `armeabi-v7a`
- **Current workaround**: Building arm32 lib from source takes 15+ min, hits CI timeout

## Solution: Use Godot 4.4-stable
**Godot 4.4-stable official export templates ARE multi-arch** (both `arm64-v8a` + `armeabi-v7a` in single APK).
- Build time: **~1-2 minutes** (no source compilation)
- Zero CI complexity
- Proven to work on 32-bit Android devices

## Verified Compatibility
✅ **GDScript APIs used**: `class_name`, `@export`, `@onready`, `signal`, `await`, typed arrays — all since Godot 4.0  
✅ **2D APIs used**: `TileMapLayer`, `TileSetAtlasSource`, `NavigationAgent2D`, `NavigationRegion2D`, `NavigationMeshSourceGeometryData2D` — all since Godot 4.0  
✅ **No 4.7-specific features**: No GDExtension, no RDShader, no RenderingDevice, no 4.7-only APIs  
✅ **Export preset**: Already declares `android/architectures=["arm64-v8a", "armeabi-v7a"]`  
✅ **Project settings**: Standard settings compatible with 4.4  

## Implementation Plan

### 1. Update Workflow Configuration (`.github/workflows/android.yml`)
- Change `GODOT_VERSION` from `"4.7.2-stable"` to `"4.4-stable"`
- Remove all arm32 build steps (source clone, SCons install, merge logic)
- Simplify to: Download headless + official templates → Export APK
- Reduce timeout from 25min to 10min
- Update cache key prefix to `godot-4.4-stable-`

### 2. Update Project Version (`project.godot`)
- Line 132: `godot_version="4.7.2"` → `godot_version="4.4"`

### 3. Verify Export Preset (`export_presets.cfg`)
- No changes needed — already specifies both architectures

### 4. Test & Validate
- Push to `kilo/briny-crane-766` → verify CI passes (~2 min)
- Download artifact → extract → verify both architectures:
  ```bash
  unzip -l game.apk | grep lib/
  # Expected:
  # lib/arm64-v8a/libgodot_android.so
  # lib/armeabi-v7a/libgodot_android.so
  ```
- Install on Redmi 10A → confirm "Install" succeeds
- Launch game → verify gameplay works
